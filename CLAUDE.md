# autocomplete — agent notes

Bash completion engine in C. Target: macOS stock `/bin/bash` 3.2 + Apple clang. Not a git repo.

## Docs policy
- This file is for agents only: constraints, verification steps, gotchas. Keep it terse.
- Never add human-facing content here (usage, install steps, tutorials, examples for users). That goes in `README.md` (overview, install, quick start) or `docs/` (`writing-specs.md` spec format, `cache.md`, `troubleshooting.md`, `how-it-works.md`).
- When a change affects users (new spec, new command, install behaviour, schema change), update the matching README/docs page; update this file only if agent-relevant facts changed.

## Files
- Sources in `src/`, each `.c` with a same-named `.h` (public API; everything else `static`). Makefile builds `src/*.c` into `./autocomplete` (binary stays at repo root: `<bin dir>/specs` lookup).
  - `main.c` — `bash`/`list`/`manage` (= `list --user`)/`diff`/`rm` (user dir only)/`check`/`alias`/`add`/`emoji`/`_complete` subcommands (`emoji` = `emoji_cmd` over `mark_names`, complete.c).
  - `complete.c` — line tokenizer (`split`), spec walk (`do_complete`), `complete_value`, `emit_commands`, `check_groups`.
  - `output.c` — candidate queue (`emit`/`emit_desc`), folding (`collapse_vars`/`collapse_flags`/`merge_pairs`/`group_flags`/`add_snippets`), `flush`. Owns the `g_*` emit-state globals (`output.h`).
  - `builtins.c` — `complete_files(dirs, globs)` (`complete_paths` adds `~user/` for `~x` words), `complete_hosts`/`_users`/`_pids`/`_processes`/`_signals` (`@hosts` etc.), `complete_cobra`, `complete_make_targets`/`_variables`, `complete_commands`, `emit_cmd_output`; seen flag values (`g_seen_*`).
  - `spec.c` — lookup dirs, `find_spec`, `load_spec`, cache, `each_spec`, `spec_desc`.
  - `util.c` — `cmp_str`, `mkdirs`, `term_width`/`term_rows`, `dwidth`.
- `yaml.c`/`yaml.h` — own YAML-subset parser → `ynode` tree (`Y_NULL/BOOL/STR/ARR/OBJ`). No numbers: non-null/bool scalars are strings. No anchors, tags, `|`/`>` scalars. Tabs in indent = error.
- `manparse.c`/`.h` — `text_spec(shell, help)` behind `man_spec`/`help_spec` (help: indent 0 allowed, `usage:` line as SYNOPSIS incl. arg-less `[--x]` (not `-abc` bundles), `Commands:` headers → `commands` without flags; else per-command usage blocks ` CMD sub [--x <a>] <file>` + deeper description line (`help_usages`, jfr) → commands with flags/args; never runs `CMD SUB --help`); root `description` always written first (`set_desc`: NAME line / `help_intro` = first unindented paragraph before options/headers, skipping usage block, version banners, `Name <mail>` / cobra `CMD --help` intro, else `man -f`, else `''`); `cobra_spec` → `{bridge: cobra}` if `CMD __complete ''` ends with `:<n>`. `man_spec(cmd)`: `MANWIDTH=1000 man -P cat | col -bx` → spec tree. Option entries = lines at the most common indent of entry-shaped lines; value from entry arg or SYNOPSIS `[-x arg]`. Heuristic; curl examples leak a few bogus flags.
- `autocomplete bash --man` (`print_bash`): after the spec line, `complete -p | <bin> _man_names` (`man_names`: names = last word of each stdin line + spec names, skipped) lists `each_man_command` names (manparse.c: `manpath` dirs' man1/man8, `.gz`/`.<digit>…` suffix cut, `plain_name`, merged with a readdir scan of `$PATH` dirs) and registers them. Don't `eval` `complete -p` output: bash 3.2 prints `-C` strings unquoted. `do_complete` falls back to `load_man_spec` (spec.c: `<cache dir>/man/NAME.yaml`, empty = no options, regenerated when the executable's mtime is newer; never runs the command, man only). ~1800 names here, init ~0.1 s.
- `autocomplete add [--force] [--from cobra|man|help] CMD` writes `~/.config/autocomplete/CMD.yaml` from the first of `sources[]` (cobra_spec, man_spec, help_spec) returning non-NULL (`--force` without `--from` reuses the old file's `generated:` source; `add_cmds` splices `generated: SRC` after `description`) via `yaml_write` (single-quotes anything ambiguous; `-1`-style keys must be quoted or PyYAML reads ints). No live man fallback: completion always comes from YAML.
- Every shipped `specs/**/*.yaml` starts with `version: 'YYYYMMDD'`: bump it to today on any change to that spec (user copies in `~/.config/autocomplete` are compared against it: `outdated()` in main.c, `list` tag via `user_tag` (`[alias -> X]` | `[override[, unchanged]|added[, generated: S][, update: …]]`), `edit` warning). `autocomplete edit NAME` (`edit_cmd`): opens the user copy (realpath, alias symlinks too), else copies `find_bundled()` (lookup dirs minus the user dir) byte for byte; editor `$VISUAL`/`$EDITOR`/`vi` via `system`; then `yaml_load` + `check_groups`.
- `autocomplete alias [--force] CMD NAME...` symlinks `~/.config/autocomplete/NAME.yaml` to the realpath of CMD's spec (no alias concept in the engine; NAME is just another spec).; `alias --rm NAME...` unlinks only symlinks there; `alias --list` prints `NAME -> CMD` (target basename), also feeds `--rm` completion.
- No compiled spec cache (removed: parse of the largest spec ≈ 1 ms); `load_spec` always parses YAML. `cache_dir` is only for man/exec/mvn/java caches.
- `specs/<topic>/*.yaml` — bundled specs in topic folders (vcs, cloud, lang, build, db, macos, net, shell, tools). `find_spec`/`find_in` search each lookup dir recursively (own files first, then sorted subdirs, depth ≤ `SPEC_DEPTH` 4); `each_spec`/`collect_specs` likewise. Spec names must stay unique across folders; cache files are keyed by name only (flat). Helper scripts (`.js`/`.sh`) sit in their spec's folder. Filename = command name; `lang/pip3.yaml` is a symlink to `pip.yaml`, `python.yaml` to `python3.yaml`, `cloud/fly.yaml` to `flyctl.yaml` (its `-m` exec always runs `python3`). Untested live here (not installed): gh, tmux, yarn, cargo, gradle, az, gcloud, doctl, flyctl, vercel, k9s, kubectx, kubens, minikube, kind, ansible, pulumi, psql, pg_dump, mysql, mysqldump, redis-cli, ffmpeg, fastlane, mas, colima, orbctl, pyenv, rbenv, asdf, nvm (shell function: must exist at registration). `specs/lang/asdf.sh` reads the plugin from `$COMP_LINE` (inherited env).
- `Makefile` — `make`, `make install` (installs `SPEC_FILES` = all `*.yaml|*.js|*.sh` under `specs/` preserving subfolders, symlinks copied as files; also appends `eval "$(autocomplete bash)"` to `$(PROFILE)` once, adding a newline first if missing), warns (no edit) when PROFILE is `~/.bashrc` and the login file (first of `.bash_profile`/`.bash_login`/`.profile`) has no `.bashrc` mention, `make uninstall` (removes only bundled specs + exact init line), `clean`. `PREFIX`, `PROFILE` overridable.
- Releases: push tag `v*` → `.github/workflows/release.yml`: `make dist TARGET=…` (`dist/autocomplete-<target>.tar.gz` = `bin/` + `share/autocomplete/` + LICENSE/README; no version in name so `releases/latest/download/…` works) for darwin-arm64/darwin-x86_64 (both on macos-14 via `-arch`, deployment target 11.0) and linux-x86_64/linux-arm64 (static musl, alpine container, native `ubuntu-24.04-arm` runner for arm64); release gets tarballs + `install.sh` + `SHA256SUMS`; then `Formula/autocomplete.rb` in `hza/homebrew-tap` is rewritten (secret `HOMEBREW_TAP_TOKEN`). `install.sh` (POSIX sh, curl or wget, default `PREFIX=~/.local`, `--uninstall`) mirrors `make install`'s profile/login-file logic; test with `base=file://<repo>/dist` substituted and `HOME=<scratch>`. A hook blocks Bash commands containing `curl … | sh` text.
- `llms.txt` (hand-written index, absolute GitHub URLs) and `llms-full.txt` (generated: `make llms-full.txt` concatenates README + docs). Regenerate only when committing (right before `git commit`), not after each README/docs edit; update `llms.txt` when docs pages are added/renamed.
- `tools/gen_npm.py` — regenerates `specs/lang/npm.yaml` from the installed npm (`npm <cmd> --help` + npm's `docs/content/using-npm/config.md`): `python3 tools/gen_npm.py specs/lang/npm.yaml`. Merges into the existing spec: hand-written root flags, command descriptions/`args`, flag values/descriptions win. Skips npm's typo aliases (`TYPOS`). Don't hand-edit generated flag lists in npm.yaml; change the generator or the hand-written parts and rerun (must be idempotent: rerun → no diff).
- find/grep value suggestions (`-mmin`, `-size`, `-name`, `-perm`, `-newermt`; grep pattern, `-C`, `--include`, `--exclude-dir` …): `specs/shell/{find,grep}.sh <kind>` print `value<TAB>desc` lines. grep spec targets BSD `/usr/bin/grep` (PATH `grep` here is ugrep).
- Snippet keys (spec `snippets` and exec `snippets: true` lines): always lowercase letters (digits only if no letter fits), mnemonic (`l` for `-L` follow redirects, `r` for RestartCount). On a collision the more useful / commonly needed snippet keeps the letter; the other takes another free letter. Mark the most used snippets (a handful per list) with `mark: pin` (exec: 4th column `pin`). `mark` may also be another name from `snippet_mark`'s table (East Asian Width W, plus keycaps `1`..`9` = 1 col with an extra U+00A0, quoted in YAML (`mark: "1"`, else PyYAML reads an int); no 📚🔎🧩) or one emoji ( single 4-byte code point U+1F300..U+1FAFF, no U+FE0F, so `dwidth` = 2 matches the terminal).
- docker `docker.sh` also prints plain `value<TAB>desc` for `log-level`, `pull`, `filter`/`filter-label` (prune `--filter`; volume prune has no `until`). The spec has a `container` group with only `prune`. docker `--format` (and inspect `-f`) values: `{exec: sh docker.sh <kind>, snippets: true}` (`specs/cloud/docker.sh`). Exec `snippets: true` (`exec_snippets`): `key<TAB>value<TAB>desc[<TAB>mark]` lines → synthesized `g_snippets` with `g_snippets_name = ""`; `add_snippets` then replaces `@key` with the whole value single-quoted (verified in pty, also `--format=@3`; main's `x@` hostname rule skips `=@`).
- java `args`: `specs/lang/java.sh` (find `*.java` declaring `void main(`, pruning target/build/out/node_modules/dot dirs; prints cwd-relative paths for source-file launch; cached in `~/.cache/autocomplete/java-mains/<cksum of cwd>`, rescanned when any non-pruned `*.java` or dir is `-newer` (dir mtime = add/delete/rename) or > 60 min); `java.sh classes` maps them under `src/{main,test}/java/` to class names for mvn `-Dexec.mainClass=` (via `$AUTOCOMPLETE_SPEC_DIR/../lang/java.sh`).
- `load_spec` exports `AUTOCOMPLETE_SPEC_DIR` (realpath dir of the spec) for `exec` helper scripts. The exec branch of `complete_value` exports `AUTOCOMPLETE_CUR` (= `g_cur`, unescaped). duti.js `keepWord`: with `filter: false`, ≥2 matches whose common prefix doesn't contain the word would make bash replace the word with that prefix; it adds a display-only `🔎<U+00A0>word` entry to break the common prefix (verified in pty). `specs/**/*.js` are installed/uninstalled with the specs. duti uses `specs/macos/duti.js` (JXA, `osascript -l JavaScript … apps|utis|args BUNDLE`: NSBundle infoDictionary scan + `LSCopyDefaultRoleHandlerForContentType`, ~0.3–0.6 s, no cache).
- `show:` on flags (set by hand). Engine: `cand.show` (from `g_show` when emitting flags): `always` is skipped by `collapse_flags`/`group_flags`; `collapsed` is always folded by `collapse_flags` into `<g_cur>📌<U+00A0><short letters>` entries, one per `coll_class` (digit/upper/lower/other, chunked by `emit_short_coll` to fit `term_width()` minus the widest name) (sorted by name, desc `(name) desc …`; `+` suffix if it would equal the long-fold `-📌`) unless nothing else remains.

## Compatibility
- Pre-release, no users yet: do NOT keep backward compatibility. Change the spec format, CLI, cache format etc. to the cleanest design and migrate the bundled specs and docs in the same change. No legacy fallbacks, aliases or dual syntaxes.

## Hard constraints
- bash 3.2: no `compopt`, `mapfile`, `${arr[-1]}`, assoc arrays; `source <(...)` silently does nothing (use `eval "$(...)"`). Init script must stay 3.2-compatible.
- Function registered with `complete -o nospace`; the engine appends a trailing space to "finished" candidates. Dirs and `nospace: true` exec values get no space. Keep this convention in any new completer (`emit(cand, space)`).
- `$`-word (bash word after the last wordbreak starts with `$`): `complete_env` (main.c) prints nothing so `-o bashdefault` falls back to bash's own variable completion (unexported shell vars too; verified in pty). Exception: `${NAME` (name chars only): names from `$AUTOCOMPLETE_VARS` emitted as `${NAME` nospace (no `}`); exact name → also the op list incl. `}` row; env unset or no match → bash. And `${NAME<op>` (last `${` of the space/quote-delimited word, since `:` is a wordbreak; also `${#`/`${!`): `complete_param` lists the matching rows of the `params` table (bash 3.2 forms; digits match the `0` placeholder; desc = `${NAME<ex>} → <result for PARAM_SAMPLE> 📚 desc`, columns padded; `op` doubles as the display name so must be unique, e.g. `%/*` dirname) display-only (`g_verbatim`, `📌`/`🔥<U+00A0>op` names, a `🔎 keep` entry when only one matches); verified in pty. Same for `x@` (char before `@` non-space: bash hostname completion, verified); bare `@word` stays ours (snippets). Side effect: any empty result gets bash default (vars/`~user`/`@host`), never filenames (no `-o default`).
- `emit`/`emit_desc` shell-escape, filter by prefix of `g_cur`, de-duplicate, trim to bash's current word using `COMP_WORDBREAKS` (needed for `image:tag`, `--flag=value`), and queue into `g_cands`; `flush()` (called once in `main` after `do_complete`) prints. Never `printf` candidates directly.
- Descriptions (`description:` on a command or flag spec): `flush` prints `name  -- desc` lines padded to > half terminal width by display width (`dwidth`; byte padding let readline fit 2 columns) (one per line) only when ≥2 candidates and any has a desc; a single candidate is always bare. Correctness relies on bash inserting only the common prefix of ambiguous matches; never let two candidates share text past the name. Each candidate has a `kind` (`g_kind` at emit time: command/file/dir/target/var, NULL for exec); if kinds differ, `flush` prefixes descriptions with a `[kind]` tag (stand-in for sections: bash 3.2 sorts the list, no `nosort`). Set `g_kind` in any new builtin completer. `collapse_vars` (start of `flush`): on empty `g_cur`, `var` candidates are replaced by one display-only `📌 vars` candidate (the gap is U+00A0: `emit_desc` escapes plain spaces) (kind target, desc = var names) unless there are no other candidates; it can't be inserted because ≥1 other candidate shares no prefix with it. Sorts last (emoji after ASCII). `collapse_flags` (after it): on `g_cur == "-"`, `--x` candidates are replaced by one insertable `--` nospace (desc = `N options: names…` cut to width, kind of the hidden ones) unless fewer than 15, all candidates fit `term_rows()-2`, or only long ones exist; emoji sorts last (verified in bash 3.2 pty). `group_flags` (after it): when `g_cur` starts with `-` and more candidates than `term_rows()-2` (tty `ws_row`, else `$LINES`, else 24), names sharing the next non-`-` char after `g_cur` (`group_len`) collapse into one `--x` entry (nospace, desc = member names; ≥2 sharing `word-` shown once as `word-🧩`; entry text = members' longest common prefix + `🧩`, e.g. `--no-🧩`; display-only: groups differ in the next char so bash never inserts the emoji, verified in pty); groups of 1 stay; then smallest groups are re-expanded while total lines ≤ limit. `groups` (any level; own then root, `find_group`): a 2-char `-x` flag whose letter is in a key is collapsed with that group (`cand.group` = key, `cand.gdesc`); `collapse_flags` emits one `<g_cur>📌 <letters>` entry per group, letters and desc `gdesc: (x) …` in key order (no width chunking); `check` exits 1 on letters without a flag (`check_groups`); `show: collapsed` on `--x` keys has no effect (`is_coll`: short only; long ones only fold into the bare-`-` `-📌`); membership `coll_member`. Collapsed entries are emitted with `g_noesc` (no shell escaping, display-only); short-flag letters via `flag_char` (cand text is escaped: `-\#`). `merge_pairs` (after `collapse_flags`): a short flag with the same desc as a listed `--long` replaces it: the long is dropped and ` (🔥 --long)` appended to the short's desc (one short per long; the user prefers short keys). Name column is padded by display width (`dwidth`: 4-byte UTF-8 = 2 cols, U+FE0F 0, keycap `d U+FE0F U+20E3` 1, matching what the user's terminal shows), not bytes.
- Listing order is readline's `strcoll` sort: every "emoji sorts last" / "📌 before 🔥" claim holds only in the C locale (no `LANG`); with `en_US.UTF-8` (VS Code terminal) macOS collation ignores emoji, entries sort by their text (verified with `strcoll`). Never rely on order for correctness.
- No colors: bash 3.2 readline prints ESC as literal `^[` in the match list (verified).
- C only, no external deps, `-Wall -Wextra` must stay warning-free.
- Spec format is YAML only (JSON support was removed deliberately; don't re-add).

## Spec schema
`{version?: 'YYYYMMDD', description?, generated?: cobra|man|help, bridge?: cobra, inherit_flags?: false, aliases?: [name], when?: {file, contains?}, flags: {name: {value?, description?, show?: always|collapsed, repeat?}}, groups?: {letters: {description?}}, snippets?: [{key, command, description?, mark?}], args: value, positional?: [value], commands: {name: spec}}`. `positional`: Nth entry for the Nth positional word (`npos` in `do_complete`'s walk: non-flag, non-flag-value, non-command words since the current command word), else `args`. `aliases` (subcommands only) are matched like the key (`find_command`) but not listed: `emit_commands` appends `(🔥 a, b)` to the command's description and emits an alias only when `g_cur` equals it exactly. A flag without `value` takes no value (`find_flag` returns the inner `value`). `bridge: cobra` (root): `do_complete` hands the whole line to `complete_cobra` (`w0 __complete w1.. cur`, directive bits 1/2/4/8/16; `--x=` → completes after `=`). Flags listing skips a value-less flag already among the typed words unless `repeat: true`. Value: null/empty (nothing), `any`, `file`, `dir`, `{file: "*.a *.b"}` (fnmatch, dirs always), `{enum: [name] | {name: desc}, suffix?, nospace?}` (static values, no popen; `label=` no space; use it instead of `exec: printf …`/`echo`), `@hosts`/`@users`/`@pids`/`@processes`/`@signals`, `{exec, suffix?, nospace?, tree?, cache?}` (`cache: N` s: `exec_cached`, output in `<cache dir>/exec/<fnv(exec,cwd,cur if $AUTOCOMPLETE_CUR used)>`) (popen, `tree: true` folds lines at the first `/` past `g_cur` into `x/` nospace (`tree: "<char>"`: fold at that char instead; duti UTIs use `.`; lines containing U+00A0 = display-only names are never folded); `filter: false` sets `g_nofilter` so `emit_desc` skips the `g_cur` prefix check (command matches by itself; bash 3.2 replaces the word with a single non-prefix candidate and keeps it for several, verified in pty), no desc (git refs), one candidate per line, `name<TAB>desc` lines give a description (copied: `emit_desc` strdups desc), `<none>` lines skipped, a line ending in `=` (`label=`) gets no space, stderr dropped), `"@subcommands"` (parent's commands), `"@command"` (as `args`: cursor word lists `$PATH` executables (kind command; a word with `/` → files); on an empty word with `snippets` (g_snippets) nothing is listed (`if <TAB>`); once a positional word without `=` and not `!` is typed, `do_complete` recurses on the line from that word, so the rest uses that command's spec; no spec → files), `"@make-variables"` (`NAME=`, names `[A-Z0-9_]` only (`upper_name`), for `=`/`:=`/`::=`/`?=`/`+=`/`!=` assignments, optional `export`/`override`, no space; same desc rules and makefile lookup as targets), `"@make-targets"` (skips `define`…`endef` bodies, as does `@make-variables`; reads `-f/--file/--makefile`, `-C/--directory` from flag values seen on the line; target description = `## text` after the deps, else the contiguous `#` comment block directly above), or a list (union). `snippets` (hand-written, never copied from third-party docs (licensing); only curl/wget/brew/lsof/find/grep/cp/mv/ln/rm/ls/ps/jfr/tar/zip/unzip/unrar/compress/uncompress/gzip/gunzip/xz/unxz/bzip2/bunzip2/ssh/jq/defaults/sips/pbcopy/pbpaste/say/duti/dutix/mdls/`docker {system,image,network,container,volume} prune`/`docker compose config`/az/gcloud/aws/kubectl/helm/terraform/rsync/openssl/dig/nc/tcpdump/rg/sed/awk/patch/diff/security/codesign/xcrun/pmset/networksetup/mdfind/doctl/flyctl/vercel/k9s/kubectx/kubens/minikube/kind/ansible/ansible-playbook/pulumi/psql/pg_dump/mysql/mysqldump/redis-cli/sqlite3/claude/diskutil/launchctl/open/screencapture/code/tmux/scp/autocomplete/plutil/hdiutil/spctl/xattr/softwareupdate/tccutil/scutil/mdutil/osascript/shortcuts/dscl/log/system_profiler/ditto/textutil/afplay/qlmanage/profiles/sw_vers/nettop/fs_usage/swift/pod/fastlane/mas/ffmpeg/pngquant/colima/orbctl/pyenv/rbenv/asdf/nvm/kill/killall/pkill/man/bun/bunx/node/npx/pip/pnpm/python3/yarn/npm and the keywords for/while/until/case/if (bash 3.2 runs `-C` completers for keywords too, with `COMP_LINE` starting at the current command after `;`/`&&`, so `then`/`do`/`else`/`elif` are plain `@command` specs; verified in pty), whose TAB lists nothing else; `add_snippets` in `flush`, after `collapse_vars`; `g_snippets` set in `do_complete`'s positional branch, only when the cursor word directly follows the current command word (`lvl`), so not after flags/args; a `@…` cursor word there completes nothing else): on `@` (or empty `g_cur` when nothing else is listed), display-only `<icon><U+00A0>@<key>` entries, icon = `mark` (`pin` → 📌: most used; or the emoji itself), else 🔥 (🔥 U+1F525 sorts after 📌 U+1F4CC, so pinned come first; no U+200B tricks: the user's terminal draws it as a space; avoid U+FE0F emoji like ➡️: drawn 1 col there) (`key`: 1-8 chars `[0-9a-z]`, `snippet_key`; `@<prefix>` of several keys lists them, of one substitutes it; `check` exits 1 on missing/invalid/duplicate keys) with desc `command   📚 description`, emitted with `g_verbatim` (no filter/escape/trim); the icons differ in the first byte so bash lists instead of inserting (verified in pty); with one icon only, the smallest key is shown 📌 (or the largest 🔥 if all are 📌); `g_cur` = `@<key>` → single candidate = command after `<g_snippets_name> ` (= `cpath` in `do_complete`: spec name + matched command keys, e.g. `docker volume prune`; snippets are written in full) (a symlinked spec, `fly` → `flyctl.yaml`, also matches with the first word replaced by `g_spec_real`, the realpath spec basename set by `load_spec`) (bash keeps the leading `@` in the replaced text: readline special prefix, verified in pty), commands not starting with that are only listed. `alias_exec` (any level; git root): popen `name expansion` lines, read once per spec (`load_aliases`); `emit_commands(spec)`: renames (exp == a command key) fold into that command's desc `(🔥 a, b)` like static `aliases`, others listed (desc `🔥 alias: exp`); later duplicate names override; walk falls back to `resolve_alias` (first non-flag word of expansion, skipping values of the spec's value flags; chains ≤ 8; `!` aliases only via `: <cmd> <sub>` hint). git has no static `aliases` anymore. `when` (subcommands only): `emit_commands` skips the command unless `file` (cwd-relative) exists and contains `contains` (plain `strstr`, no popen); `find_command` ignores it. mvn `-Dtest=`/`-Dit.test=` use `specs/build/mvn.sh unit|it` (find `*/src/test/**` by surefire/failsafe name patterns, always cached in `~/.cache/autocomplete/mvn-tests/<cksum of cwd>{.files,-<mode>[-Class]}`, valid while no file under the `*/src/test` roots listed in `.files` is `-newer` and ≤ 60 min old, `Class#` → `@Test`-style methods via awk, comma lists keep the prefix; nospace). mvn plugin goals use it on `<artifactId>X</artifactId>` in pom.xml. Root flags are matched and listed at every depth (listing: own flags then root's), unless the root has `inherit_flags: false` (`root_flags()` returns NULL below the root; docker: global options only before the subcommand). Empty-word fallback (end of `do_complete`, `list_flags(..., 0)`): below the root, when nothing was queued (`ncands()`) and there are no snippets, the command's own flags are listed (no root ones); `merge_pairs` also runs on an empty word when every candidate is a flag. A flag key ending in `=` (mvn `-Dtest=`) is emitted without a space. Its `value` completes after the `=` (`-Dx=` branch in `do_complete`, before `--x=`). Open quote after `=` (`-Dx='a b`): `g_qpre` = text after the quote up to the last space; `emit_desc` emits `g_qpre`+cand unescaped, untrimmed, no space (readline closes the quote; verified in pty); words already in `g_qpre` are skipped. Bare words (without `g_qpre`) don't work: bash replaces the whole quoted text with their common prefix (verified), so listings repeat `g_qpre`. Lookup dirs: `$AUTOCOMPLETE_SPECS` (colon list) → `~/.config/autocomplete` → `<bin dir>/specs` → `<bin dir>/../share/autocomplete`; first `<cmd>.yaml|.yml` wins (searched recursively in each dir).

## Verify after changes
- `make` — zero warnings.

A second `\t` in the harness didn't trigger the list.

## Gotchas
- The harness safety check rejects `bash -c '...'` scripts containing ` rm` (e.g. a test line `git remote rm`); run such cases outside `bash -c`.
- `print_bash` embeds the absolute path of the binary when invoked with a path, bare name otherwise (resolved via PATH at TAB time).
- `exec` commands run in the shell's cwd, not in `git -C`/`make -C` dirs (only `@make-targets`/`@make-variables` honour `-C`).
